# CodeBuddy 模型选型指引

> **本文件不维护实时价格。** 价格、积分、套餐权益随时可能调整，一律以官方页面为准。
> 这里只回答一个问题：**什么场景该用哪一档模型**。

## 获取最新价格

价格数字不在本文件里复制、缓存，避免过期误导。要看实时价格，请查以下官方来源：

1. **官方定价页**：<https://copilot.tencent.com/pricing>
   （套餐档位、月付/年付价、各档积分额度）
2. **官方积分说明**：<https://www.codebuddy.ai/docs/zh/ide/Account/credits>
   （积分怎么算、怎么扣、各模型相对倍率）
3. **CLI 里查余额**：登录 [codebuddy.ai](https://www.codebuddy.ai) → 头像 → 个人主页 → 用量

也可以直接跑本仓库的 `scripts/fetch_pricing.sh`，它会抓官方定价页并尽量抽出价格关键词；
该页面是动态渲染的，抓不到数字时会提示你手动打开网页查看。

## 模型分档（只记档位，不记价格）

| 档位 | 代表模型 | 什么时候用 |
|---|---|---|
| **默认（只读轻活）** | `hy3` | x0.00 免费。查状态、读日志、看 git log 这类简单只读任务，默认就用它 |
| **编码干活** | `space-bunny` | x0.08。写代码、改文件、跑测试这类正经编码任务，切到它 |
| **兜底** | `glm-5.3-flash` | x0.06。只有 `hy3` 撞到每日限额、不可用时，才切过来顶上 |

> 旗舰模型（`deepseek-v4-pro` / `kimi-k3-2` / `glm-5.3`）默认不用，只有用户显式点名才上。
> 需要看截图/图片时，`space-bunny` 本身支持图片输入；用户自配第三方端点用 `custom-local:*`。
> 各档的具体模型清单和相对倍率以官方积分说明为准，本表只做选型导航，不写价格数字。

## 选型规则

1. **简单只读任务默认用 `hy3`**（免费，x0.00）：查状态、读日志、看 git log 这类轻活。
2. **正经编码任务用 `space-bunny`**（x0.08）：写代码、改文件、跑测试。
3. **`glm-5.3-flash`（x0.06）只做兜底**：只有 `hy3` 撞到每日限额、不可用时才切过来。
4. **不用旗舰档**（`deepseek-v4-pro` / `kimi-k3-2` / `glm-5.3`），除非用户显式点名。
5. **用户明确点名某个模型** → 用用户指定的。
6. **需要看图/截图** → `space-bunny` 本身支持图片输入。

## 省钱原则

- 简单只读任务默认 `hy3`，免费（x0.00）。
- 正经编码任务用 `space-bunny`（x0.08）。
- `glm-5.3-flash`（x0.06）只做兜底：只有 `hy3` 撞每日限额不可用时才切过来。
- 旗舰档默认不用，只有用户显式点名才上。
- 想估算花费，去上面「获取最新价格」的三个官方来源看实时数据，别信任何写死的数字。
